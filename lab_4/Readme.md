# Лабораторная работа №4 — HMAC и поиск коллизий хешей

## Описание проекта

**Вариант 4** — реализация HMAC-SHA256 для аутентификации сообщений: генерация кода, верификация, обнаружение подделки.

Приложение поддерживает:
- графический интерфейс (PyQt5);
- корректную обработку всех исключений.

## Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

`requirements.txt`:
```
PyQt5>=5.15
```

### 2. Запуск в режиме GUI (по умолчанию)

```bash
python main.py
# или явно:
python main.py --mode gui
```

### 3. Запуск через командную строку

#### Вычислить HMAC:
```bash
python main.py --mode hmac --message "Hello, world!" --key "mysecretkey"
# Вывод: HMAC-SHA256: 3b2c1f...
```

#### Проверить HMAC:
```bash
python main.py --mode verify --message "Hello, world!" --key "mysecretkey" --hmac "3b2c1f..."
# Вывод: Result: Matches  /  Result: Does not match
```

## Как пользоваться приложением

### Вкладка HMAC

1. Введите текст сообщения в поле **Message**.
2. Введите секретный ключ в поле **Secret key** (поле скрывает ввод).
3. Нажмите **Compute HMAC** — в поле результата появится 64-символьный hex-код.
4. Нажмите **Verify HMAC** — статус покажет, совпадает ли HMAC с текущим содержимым поля.
5. Нажмите **Tamper message** — первый символ сообщения будет заменён случайным символом Unicode.
6. Снова нажмите **Verify HMAC** — статус покажет `HMAC mismatch! Message or key modified.`

**Демонстрация обнаружения подделки:**

| Шаг | Действие | Результат |
|---|---|---|
| 1 | Ввести сообщение и ключ, нажать Compute HMAC | HMAC вычислен |
| 2 | Нажать Verify HMAC | `Authenticity confirmed` |
| 3 | Нажать Tamper message | Сообщение изменено |
| 4 | Нажать Verify HMAC | `HMAC mismatch!` |

## Вывод

В ходе выполнения лабораторной работы был изучен и реализован механизм
аутентификации сообщений на основе HMAC-SHA256.
Реализованная система выполняет полный цикл аутентификации: вычисление кода
HMAC по секретному ключу и сообщению, передачу пары (сообщение, HMAC),
верификацию на принимающей стороне и обнаружение несанкционированных изменений.
Практическая проверка подтвердила теоретические свойства HMAC. Изменение даже
одного символа сообщения приводит к полному несовпадению HMAC-кодов — это
следствие лавинного эффекта SHA-256, при котором изменение одного входного бита
меняет в среднем половину выходных бит. Попытка верифицировать подделанное
сообщение неизменно завершается ошибкой, что подтверждается как ручным
тестированием в GUI, так и автоматическими тестами.
